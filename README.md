# 🏴‍☠️ FanGameOne — One Piece Survivors

Videojuego fanmade de supervivencia, acción y aventura inspirado en el universo de **One Piece** y en la jugabilidad de **PokeSurvivor**.

## 🎮 Descripción

FanGameOne es un proyecto de videojuego 2D desarrollado con estética pixel art, vista superior (top-down) y mecánicas roguelite de supervivencia.

El jugador controla personajes del universo One Piece, explora distintas islas, combate oleadas de enemigos, obtiene experiencia, mejora habilidades y enfrenta poderosos jefes.

**Objetivo:** crear un juego entretenido, fluido, visualmente atractivo y con suficiente profundidad para ofrecer múltiples partidas diferentes.

## ⚔️ Jugabilidad

El juego toma como referencia las mecánicas de PokeSurvivor, adaptándolas a la temática pirata.

### Sistemas principales

- Movimiento libre por escenarios explorables.
- Cámara que sigue al personaje.
- Ataques automáticos y técnicas especiales.
- Enemigos con diferentes comportamientos.
- Oleadas de dificultad progresiva.
- Experiencia y subida de niveles.
- Selección de habilidades y mejoras.
- Evoluciones y combinaciones de habilidades.
- Minijefes y jefes principales.
- Recompensas, monedas y progresión permanente.
- Selección y desbloqueo de personajes.

Las mecánicas se implementarán progresivamente, priorizando calidad, estabilidad y rendimiento.

## 👒 Personajes

El prototipo inicial contempla cinco personajes jugables:

| Personaje | Estilo de combate |
|---|---|
| Luffy | Combate cuerpo a cuerpo y técnicas elásticas |
| Zoro | Espadas y ataques de área |
| Nami | Bastón y técnicas climáticas |
| Usopp | Ataques y proyectiles a distancia |
| Sanji | Patadas y técnicas de fuego |

En futuras versiones se podrán incorporar más personajes, habilidades, evoluciones y combinaciones especiales.

Cada personaje deberá contar con estadísticas, identidad de combate y animaciones propias.

## 🏝️ Islas y escenarios

El prototipo incluye cinco capítulos iniciales:

| Isla | Jefe principal |
|---|---|
| Shells Town | Morgan |
| Orange Town | Buggy |
| Villa Syrup | Kuro |
| Baratie | Don Krieg |
| Arlong Park | Arlong |

Los escenarios deberán contar con identidad visual propia, enemigos temáticos, elementos ambientales, obstáculos y áreas explorables.

## 🎨 Diseño gráfico

### Pixel art

- Gráficos 2D top-down.
- Sprites con proporciones consistentes.
- Animaciones de movimiento, ataque y habilidades.
- Efectos visuales de combate.
- Escenarios detallados y ambientados en One Piece.
- Interfaz clara y adaptada a la temática pirata.

### Referencias visuales

Se utilizarán las imágenes proporcionadas para orientar el diseño:

- Sprites pixel art: personajes y animaciones jugables.
- Ilustraciones detalladas: retratos, selección de personajes y menús.
- PokeSurvivor: referencia para la experiencia de juego y ciertos sistemas técnicos.

Se buscará mantener una estética coherente en todos los recursos.

## 🛠️ Tecnologías

El prototipo está desarrollado utilizando:

- HTML5.
- CSS3.
- JavaScript.
- Canvas 2D.

La arquitectura podrá optimizarse y modularizarse sin cambiar innecesariamente las tecnologías existentes.
